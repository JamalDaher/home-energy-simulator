# Home Energy Simulator — v1.2 release candidate

> Release preparation notes. This document is not a published GitHub release or tag.

## Highlights

- Generator-only, battery-only and hybrid backup comparisons with energy-demand coverage and cost assumptions.
- Multi-day outage simulations with finite fuel inventory and load-dependent or constant-rate generator fuel models.
- FIRMAN T07571 and W03386 profile selectors with user-verified running ratings, plus manual generator configurations.
- Upfront equipment and installation costs, annual operating estimates and 5-, 10- and 20-year ownership projections.
- More compact backup comparison interface, clearer fuel configuration and responsive navigation.
- Additional regression coverage for zero-battery configurations, fuel depletion and stale comparison results.
- Updated README, GitHub Pages case study and CI startup smoke test.

## Important limitations

This is educational scenario analysis, not certified electrical system design or a forecast of outage reliability. Fuel rates and generator ratings are user-supplied; hourly dispatch cannot model surge currents, transfer-switch safety or equipment protection. Ownership projections are simplified assumptions and exclude financing, inflation, replacement cycles, taxes, incentives and grid savings. The scenario workspace PDF uses the legacy unlimited-fuel outage model.
